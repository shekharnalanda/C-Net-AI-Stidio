Master Admin > AI Worker Management

STEP 2
Extract this ZIP on the Windows computer.

STEP 3
Double-click:

INSTALL-C-NET-AI-WORKER.cmd

STEP 4
Enter the one-time Activation Code when requested.

The installer is successful ONLY if it displays:

C-NET AI WORKER V5.1 INSTALLATION VERIFIED SUCCESS

and the worker appears in:

Master Admin > AI Worker Management > Registered Workers

After installation, start continuous processing with:

START-C-NET-AI-WORKER.cmd

No database password, GitHub password, or server worker token
needs to be manually entered on the Windows computer.
